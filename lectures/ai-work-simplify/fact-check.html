  • 핵심 결과물은 내용 확인·디자인 적용·수정을 거쳐 내 컴퓨터에서 열리는 HTML 발표자료 한 편입니다.
  • 한글파일과 데이터 분석은 생성 대기 중 업무팁입니다. 원래 대화를 유지하고 복귀 후 발표자료 확인·수정·저장을 우선합니다.
  • 전환 장표와 실습 신호 화면에 현재 위치, 원래 작업, 우선 행동, 열 화면·유지할 화면, 복귀 기준을 넣었습니다. 실제 생성 상태를 감지하거나 표시하는 기능은 없습니다.
  • 먼저 끝난 사람은 파일과 대화를 보관하고 안내된 활동에 참여합니다. 미완료자는 중복 요청하지 않으며 보조 강사가 상태를 확인합니다. 예제가 실제 등록되어 있으면 활용하고, 그렇지 않으면 강사 시연으로 점검 기준을 익힙니다.
